# Merlin · arquitetura em C4

Três níveis de zoom, do mundo para dentro. Servem para entender como as partes se relacionam
sem ler código, que muda rápido. **Quem muda uma fronteira daqui atualiza o diagrama no mesmo
PR** (`docs/workflow.md`). O detalhe de cada peça está em [PROJETO.md](../../PROJETO.md).

Levantado do código em 17/10/2026.

## 1. Contexto: quem usa e com quem o Merlin fala

```mermaid
C4Context
  title Merlin · contexto
  Person(owner, "Pessoa autorizada", "Um e-mail de OWNER_EMAILS. Cada uma tem um Merlin isolado")
  Person(visitor, "Visitante", "Quem chega na landing, sem conta")
  Person(reader, "Leitor de link", "Abre um mapa ou funil compartilhado")
  System(merlin, "Merlin", "Dia, calendário, notas, clientes, conteúdo, funis, mapas, produtos, financeiro, hábitos, sono, treino, diário")
  System_Ext(resend, "Resend", "Envia o código de 6 dígitos do login")
  System_Ext(anthropic, "Anthropic API", "O conselheiro: conversa, propostas, rascunhos")
  System_Ext(cf, "Cloudflare Web Analytics", "Mede só a landing")
  Rel(owner, merlin, "usa", "navegador, desktop, extensão")
  Rel(visitor, merlin, "lê a landing e entra na lista de espera")
  Rel(reader, merlin, "lê sem conta", "share.html#token")
  Rel(merlin, resend, "manda código", "HTTPS")
  Rel(merlin, anthropic, "pede conselho", "HTTPS, teto por pessoa/hora")
  Rel(visitor, cf, "beacon", "só em html.bare")
```

## 2. Contêineres: o que roda onde

```mermaid
C4Container
  title Merlin · contêineres
  Person(owner, "Pessoa autorizada")
  System_Boundary(merlin, "Merlin") {
    Container(web, "App web", "React 19 + Vite", "Uma página por módulo (<nome>.html + src/<nome>.jsx). Fonte de verdade local: localStorage merlin:<type>")
    Container(desktop, "App desktop", "Tauri 2", "Casca do site publicado + rastreador sempre por cima")
    Container(ext, "Extensão", "Chrome MV3", "Nota rápida (Alt+Shift+N)")
    Container(worker, "Worker", "Cloudflare Worker, sem dependências", "Serve server/site/ e /api/*: login, docs por versão, conselheiro, arquivos, links")
    ContainerDb(d1, "D1", "SQLite", "people, codes, days, docs, advice, usage, shares, waitlist. Tudo por person")
    ContainerDb(r2, "R2", "merlin-files", "Anexos")
  }
  System_Ext(resend, "Resend")
  System_Ext(anthropic, "Anthropic API")
  Rel(owner, web, "usa")
  Rel(owner, desktop, "usa")
  Rel(owner, ext, "anota")
  Rel(desktop, worker, "abre o site", "HTTPS")
  Rel(web, worker, "sincroniza documento (último vence, 409 em versão velha)", "POST /api/docs")
  Rel(ext, worker, "POST /api/quick-note")
  Rel(worker, d1, "lê/grava")
  Rel(worker, r2, "anexos")
  Rel(worker, resend, "código de login")
  Rel(worker, anthropic, "/api/merlin")
```

## 3. Componentes do app web

```mermaid
flowchart TB
  subgraph page["uma página (ex.: content.html)"]
    html["&lt;nome&gt;.html<br/>CSS inline, anti-flash do tema"] --> screen["src/&lt;nome&gt;.jsx<br/>a tela"]
  end
  screen --> ui["shared/ui.jsx<br/>hooks, Form/Dialog, casca, Ctrl+K"]
  screen --> rules["shared/*.js<br/>regras puras: tasks, day, routine,<br/>board, client-doc, templates, app-spec, portrait"]
  ui --> core["shared/core.js<br/>DADOS: coleções, sessão, sync,<br/>datas, dinheiro, aviso com desfazer"]
  rules --> core
  core <--> ls[("localStorage<br/>merlin:&lt;type&gt;")]
  core <-->|"/api/docs, /api/days"| worker["Worker"]
  screen -->|"/api/merlin"| worker
```

Regras que os diagramas pressupõem: a tela nunca toca o `localStorage` direto (só pelo
`core.js`); a lógica pura vive em `shared/*.js` e é testada sem navegador; e o servidor não
entende o conteúdo dos documentos, só guarda cada um com a versão e diz qual é a mais nova.
Por isso o resumo das áreas que vai junto de cada pergunta ao Merlin (o retrato,
`shared/portrait.js`) é montado na tela, das coleções locais, e viaja no pedido a
`/api/merlin`: o Worker o repassa à Anthropic sem ler documento nenhum.
